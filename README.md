# Higher-or-Lower-project
Overview
This is a fun Higher or Lower game where you have to guess which of the two random accounts has more followers on social media. Each round, you are shown two accounts with their description, and you have to guess whether account A or account B has more followers. The game continues until you make an incorrect guess, and your score is displayed.

Features
Randomized Accounts: Two random accounts from the game data are selected each round.
Follower Count Comparison: Compare the follower count of two accounts and make a guess.
Score Tracking: Your score is tracked across the rounds, and you see your current score after each correct guess.
Game Flow: The game continues as long as you keep guessing correctly. It stops when you make a wrong guess and shows your final score.
                                
Requirements
Python 3.x
art and game_data are external dependencies:
art module: For displaying ASCII art in the game.
game_data file: This file should contain data of accounts, including name, description, country, and follower count.
